# Smart Healthcare Data Analysis

## Project Overview
This project analyzes daily lifestyle data from wearable-device records using Python.

## Tools Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Features
- Heart rate and blood oxygen distribution
- Step count and distance analysis
- Screen time and sleep duration analysis
- BMI distribution
- Gender-based sleep comparison
- Correlation heatmap

## Disclaimer
This project is for educational purposes and is not intended for medical diagnosis.
